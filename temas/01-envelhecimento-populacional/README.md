# Envelhecimento populacional

## Pergunta investigada

Como mudou a estrutura etária da população de Varginha entre os Censos de 2010 e 2022?

Esta investigação compara a distribuição da população por idade e utiliza indicadores para analisar o envelhecimento populacional.

## Aplicação a outros municípios

O script deste tema será preparado para consultar dados oficiais e reproduzir a análise para outro município.

O usuário poderá alterar o código IBGE do município no início do script, conforme as instruções que acompanharão sua disponibilização.

## Fonte dos dados

Instituto Brasileiro de Geografia e Estatística — IBGE.

Os dados serão obtidos no Sistema IBGE de Recuperação Automática — SIDRA. As tabelas, os filtros e as definições utilizados serão documentados junto ao script.

## Indicadores

- População por faixa etária.
- Participação percentual de cada faixa etária.
- Variação da população dos grupos etários.
- Índice de envelhecimento.

O corte etário adotado para a população idosa será informado explicitamente e mantido nas comparações.
